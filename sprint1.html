Ce document résume tout le travail réalisé jusqu'à maintenant dans le dossier C:\Users\dell\Desktop\winners pour les modules Odoo 17 winners_auth, winners_student et winners_teacher.

Résumé général

winners_auth Module d'authentification et de rôles. Il étend res.users et définit les groupes de sécurité Winners Academy.
winners_student Module de gestion des élèves. Il définit le modèle winners.student avec ses champs principaux et ses droits d'accès.
winners_teacher Module de gestion des enseignants. Il définit le modèle winners.teacher avec ses champs principaux et ses droits d'accès.
Les trois modules sont configurés pour Odoo 17 avec la version 17.0.1.0.0 et la catégorie fonctionnelle Winners Academy.

Extension de res.users

Le fichier winners_auth/models/winners_user.py étend le modèle standard Odoo res.users avec _inherit = "res.users".

Champ Type Détails
winners_role Selection Rôle Winners, défaut secretary. Valeurs : super_admin, director, secretary, teacher, cashier.
branch_id Many2one Relation vers winners.branch, libellé Branche. Le modèle winners.branch n'a pas été créé pendant ce sprint.
is_active_winners Boolean Libellé Actif Winners, défaut True.

Groupes de sécurité

Le fichier winners_auth/security/security.xml crée la catégorie Winners Academy puis les groupes Odoo suivants :

ID XML Nom affiché Catégorie
winners_group_super_adminSuper administrateurWinners Academy
winners_group_directorDirecteurWinners Academy
winners_group_secretarySecrétaireWinners Academy
winners_group_teacherEnseignantWinners Academy
winners_group_cashierCaissierWinners Academy

Le groupe winners_group_super_admin implique automatiquement les groupes winners_group_director, winners_group_secretary, winners_group_teacher et winners_group_cashier via implied_ids.
